# Campus Notes

## Project Overview
Campus Notes is a Version Control System assignment project created to demonstrate the use of Git and GitHub for managing project files and tracking changes.

## Features
- Organized project documentation.
- Version control using Git.
- Repository management using GitHub.
- Feature branch development.
- Collaboration through Fork and Pull Requests.

## Technologies Used
- Git
- GitHub
- Markdown

## Git Workflow
This project demonstrates:
1. Repository creation.
2. Cloning repositories.
3. Creating and managing branches.
4. Committing and pushing changes.
5. Collaboration using Forks and Pull Requests.
